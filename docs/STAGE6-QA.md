# 第六阶段：关卡、经济与完整质量验收

日期：2026-10-17。结论：本地候选完成本阶段验收，可以进入交付准备；**尚不能把当前公网入口当作最终提交版本**。尚未推送、部署或公开更新 Session。源码及构建标识见 [候选快照](verification/stage6-candidate.json)。

## 1. 源码确认与关卡判断

重新阅读模型、商品配置、活动时钟、表现层、UI 和现有验收入口，确认实际调用链仍为：输入 → 三态钩爪 → 扫掠首次碰撞 → 一次性占用采集包 → 按总重量回收 → 到地面一次入账。没有用动画回调补抓或发钱。

| 关卡 | 时间 | 累计目标 | 本关最低采集 | 地图总值 | 设计职责与取舍 |
| --- | ---: | ---: | ---: | ---: | --- |
| 晨光矿谷 | 60s | $650 | $650 | $2700 | 认识金块价值与重量；保留一颗安全水晶帮助理解连带。精确抓到钻石即可达到第一关目标，这是教学关的宽容度，不强迫玩家用水晶 |
| 琥珀回廊 | 60s | $2600 | $1400 | $3285 | 两颗水晶形成干净矿团与混石矿团对照；两颗钻石合计 $1300，仍需其他收益满足采集要求，购物支出可能进一步增加缺口 |
| 星辉深井 | 60s | $4800 | **$2200** | $3835 | 浅层快收与深层重载并存，要求组合更多有效采集，并判断整包能否及时收回 |

沙漏只把购买后的下一关增加至 70 秒。固定三关分别为 12/13/13 件矿物，石头 2/3/3 块、钻石 1/2/3 颗、水晶 1/2/2 颗。没有随机地图，也没有失败后重新抽取有利布局的随机性。

本轮保留矿物坐标、数量、基础价值、重量、连接范围、数量上限和回收公式。布局已有不同风险矿团和普通采集路径，新增边界路线证明不需要为了“重新设计”而任意搬动矿物。

第三关最低采集额由 $1800 提高至 $2200，累计目标 $4800 不变，判定含义不变。原门槛低于三颗钻石总值 $1950，高余额玩家所需的采集组合较少；新门槛促使其继续组合其他矿物。**深层钻石有水晶遮挡，不能把“三颗钻石总值”误写成开局三钩直接可达的路线或漏洞。** 本轮测试只把 $1950 作为结算边界，实际通路由正常运动路线另行证明。

教学副标题分别强调“价值与重量／先看连线／留足深层回收时间”。达到两个目标后，状态条明确提示可以继续收集，并说明时间到后结算；没有提前结束关卡或改变计分。

## 2. 共振与五道具是否有实际价值

下表为完整矿团、未抛光、未喝力量药水时的模型数据。回收速度单位为世界像素/秒，不等于整个出钩周期耗时。

| 矿团 | 基础收益 / 重量 / 回收速度 | 增幅后 | 策略含义 |
| --- | --- | --- | --- |
| 第二关干净矿团 | $470 / 4.6 / 94.4 | $570 / 5.6 / 80.8 | 多赚 $100，但更慢；$80 购价只有完整回收后才可能获得额外净收益 |
| 第二关混石矿团 | $635 / 14.1 / 36.3 | 不变，没有第三个合格候选 | 价值略高而等待明显更长，不能因为是水晶就默认优先 |
| 第三关浅层矿团 | $770 / 1.35 / 208.7 | 不变 | 稳定、轻量收益，是另一条可行路线的一部分 |
| 第三关深层矿团 | $635 / 14.1 / 36.3 | $1285 / 14.65 / 35.0 | 增幅多带钻石，但整包仍沉重；截止前未回收全部不入账 |

共振只有一次范围查询，110 像素内按距离、稳定 ID 选取，默认最多连带两件，增幅后最多三件；其他水晶不继续传播。快照、去重、占用、炸毁及超时规则保持原样。上述数据与源码哈希保存在 [候选快照](verification/stage6-candidate.json)。

| 道具 | 保留价格 | 合理用途与局限 |
| --- | ---: | --- |
| 炸药 | $100 | 主动销毁错误的重包，空钩快速返回；牺牲整包收益。正常试玩实际炸毁抛光石头，库存减少、收入不增加 |
| 力量 | $150 | 载物回收速度 ×1.5，减少回收部分约三分之一的耗时；不改变瞄准、伸出和空钩速度。要通过更多有效采集覆盖支出 |
| 沙漏 | $200 | 多 10 秒容错；失败重试恢复 70 秒，不叠加到 80 秒。熟练路线可能不需要，不能声称必买 |
| 抛光 | $20 | 每块石头额外 $15，后两关各三块，理论最多增收 $45；至少回收两块才覆盖成本。适合本来就要带石头的路线，不能把裸抓重石头说成普遍高效 |
| 增幅 | $80 | 第二关可增加 $100，第三关深层可增加 $650，并承担重量；先采走邻居会减少实际连带，商品说明已明确提醒 |

只有两次购物机会，分别服务于第二、三关；五商品都能在这两关体验。价格没有在本阶段再次改变。每店每种一次、不同强化可组合、关末到期、重试入口恢复和炸药余量跨关保留，均有规则及浏览器验证。

这些证据证明各道具存在用途，**没有证明五件商品等强、每局都值得买或人类玩家都能看懂**。本人试玩仍是后续确认价格与音量的必要补充。

## 3. 容错路线与经济边界

新增 `tests/balance.test.ts`，从“上一关刚好达到累计目标”的商店准备合法入口，然后实际购买、进入下一关；进入待测关后只发射、等待模型运动，不改时间或直接加钱。

- 第二、三关 × 不买／分别买五种商品／全部购买 × -0.02、0、+0.02 弧度误差，共 **42 条**模型路线通过，每条先发射两次空钩。
- 另有 **2 条**不买道具、不抓水晶的普通路线通过，同样先发两次空钩；第二关约 25.6 秒达标，第三关约 45.1 秒达标，分别剩约 34.4、14.9 秒。
- 原有七条完整三关路线继续通过，包括单种强化、全部购买和普通采集。
- 固定地图重试后完全重现；初始矿物无圆形碰撞体重叠，显示范围位于画布内。
- 高余额入口只入账 $1950 仍失败，重试回到原入口，失败收入不会累加；到 $2200 且钱包足够才通关。

路线使用规则数据做选择，是可行性和小角度容错的证据，**不是 42 名玩家通过、不是最优解证明，也不覆盖所有购买组合**。详见 [最终路线输出](verification/stage6-balance-final.log)，旧门槛的初次输出保留在 `stage6-balance-first.log`。

累计钱包规则未改：消费只降低下一关入口余额，不回退上一关过关结果，也不降低累计目标。最紧的“第一关 $650、全部买 $550”入口只有 $100，第二关仍需赚 $2500；实际模型路线在该入口可通过。

自然输入路径未发现无限刷分或重复领奖：入账后清空包、已抓取 ID 不再参与碰撞；重复购买被模型拦截；`finish` 只接受游玩阶段；失败恢复入口钱包与矿物，回首页重开清空本局。已有去重、重复回调、截止优先及重复输入测试继续通过。游戏为本地客户端逻辑，不把这些验证扩大成有后端防作弊能力的声明。
