## 已实现的范围

六关目标依次为 $650／1800／3400／5500／8000／11000，每关60秒，以累计钱包为唯一通关条件。可提前结束本关，未达标失败；失败整局重开，初始炸药为零。消费扣钱包，余额富裕时允许少采或零采。移除共振、水晶、连锁采集、增幅器、沙漏、旧石头抛光剂、双目标和关内重试，不保留双模式。

新增问号袋、骨头、头骨、往返移动鼹鼠、携钻鼹鼠及 TNT。六幅固定地图依次有12／14／16／18／19／21件物品，内容递进；每个商店后的关卡都有袋子、石头和钻石。没有随机放置矿物。详细商品、价值、概率及操作见 [README](../README.md)。

参考 [CrazyGames 单人 Gold Miner](https://www.crazygames.com/game/gold-miner) 的经典构图和操作行为，采用1100×800画布、黄色顶部金额/目标/时间/关卡、橙色土地、中央矿工和卷扬机。本项目是六关适配：不声称目标、布局、价格、动物速度和袋子概率与商业原版完全一致，未复制商业图片或原版程序。

## 实现与模块职责

| 模块 | 改造与取舍 |
| --- | --- |
| src/core/model.ts | 保留 swinging / extending / returning 三态。单件 CatchSnapshot 固定价值、重量和接触偏移，抵达绞盘才发 bank 事件；截止、炸毁、提前结束不补钱。 |
| src/core/model.ts 动物 | 有限范围水平往返，模型时钟驱动。碰撞比较钩尖与目标的相对位移，取最早接触；被抓后立即停止自主运动，回收期间不重复碰撞。 |
| src/core/model.ts TNT | 钩中立即引爆中心110世界像素内物品。队列与 ID Set 去重并传播相邻TNT，每个物品至多处理一次，不发收益，也不消耗背包炸药。 |
| src/core/shop.ts | 五商品小型配置表、本店固定 ShopOffer、可复现种子随机数与袋子权重。购买验证与物品效果执行分开；不引入通用技能框架。 |
| src/core/clock.ts | 单调活动时钟排除暂停、菜单、商店。主线程长帧后仍补算活动时间，模型内部按1/120秒切片，超时优先于同一截止瞬间的入账。 |
| src/presentation.ts | 身体、上臂、前臂、手掌分开；两段手臂解算跟随与手柄绘制共用的 knob 坐标。身体脚底固定；120ms姿态混合；摇柄随实际收放绳距离变化，视觉减速比0.18。 |
| src/main.ts | 场景装配、输入、DOM与事件反馈。矿物保留接触偏移，动画不操作金钱。暂停冻结人物、动物、载物与反馈；切关/重开清除旧姿态、粒子、相机偏移。 |
| public/assets/classic | 10张项目原创SVG，统一描边。旧网络PNG保留来源历史但经典场景不加载；详情见 [ASSETS](ASSETS.md)。 |

回收速度保持 420 ÷（1 + 重量 ×0.75），药水使分子成为630，空钩600。普通抓取始终一件，重物耗时、移动目标要求判断时机，TNT清路同时损失范围内矿物，问号袋可能低收益。没有无限扩张或额外免费奖励。

袋子金额在进入关卡时一次抽定，正常35/30/20/10/5%，幸运草10/15/30/25/20%，对应$50/100/250/500/800；回收前UI只显示问号。商店报价同样一次生成，重绘不抽取。炸药库存跨关；四种强化可组合、只在下一关有效，关末清除；整局重开全部清空。

## 本轮失败与修复记录

首次浏览器5/8通过，三处失败与修复均保留在 [首轮日志](verification/classic-browser-first.log)：

1. 超时用例在开局就抓取，物品在快进时合法回收到达，应该付钱。改为临近截止抓重石，并断言回收所需时间大于剩余时间，没有放宽结算规则。
2. 资源失败测试仍匹配旧PNG路径，改为当前关键SVG。真实加载失败界面原已能保留重试。
3. 暂停按钮实际宽度偏小，扩大桌面最小40、横屏32像素后复验。

规则首次运行还纠正了“已回收一段时间后再比较首次接触位置”的测试采样点；姿态的负零已归一化。经济测试的空钩曾遇移动鼹鼠，修正路线选择的移动包围范围；没有删除移动物或提高收入。保留 [首次规则记录](verification/classic-core-first.log) 与后续报告。

正常时钟全流程脚本首次要求第一关先采$1600以一次购买五商品，实际采$1250后到时，脚本因此停止，控制台异常0；已达游戏$650目标，但没有达该脚本的额外购物目标。[原始记录](verification/classic-normal-first.json)。第二次正常目标脚本也只采$500而未达$650，记录见 [第二次失败](verification/classic-normal-second.json)。自动瞄准原先使用0.012弧度窗口，正常时钟存在协议和帧延迟，现按目标实际角宽的一部分设置容差（最大0.055弧度），虚拟时钟窗口保持不变，没有修改游戏碰撞或放宽目标。第三次正常目标、选择性购物的完整六关通过；失败历史不删除。
