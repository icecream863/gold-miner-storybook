# 第一关体验纠偏：矢量样片

本轮只替换独立第一关样片。六关入口、模型、商店、原1.3音频与表现模块均保留；没有推送、部署或更新公开Session。

## 改了什么

- 原样片把系统“减少动态”映射为回收帧0。现在减少动态仍保留摇柄、收放绳与握柄动作，只取消眨眼和循环用力起伏；暂停冻结全部活动姿态。
- 停用生成PNG帧图。`src/sample/art.ts`绘制同一套矢量角色、衣袖、前臂、手掌、机械、矿物和袋子；金块改为不规则矿石轮廓与切面。
- 矿工改到机器右侧、侧身面向机器。肘部使用人工校准的八个姿势和循环曲线插值；手掌与手柄读取同一目标，120ms握柄过渡。脚和靴底固定，重载肩背前倾，轻载姿态较直。
- 卷筒、手柄使用同一个旋转相位，出绳时反转、回收时正转。动作由实际绳长变化驱动，未调整默认摆速、发射、回收公式、价值和结算。
- 音效按试听选择恢复A版：直接使用1.3的launch/grab/bank/reel文件、增益及收钱音阶。绞盘恢复原0.16/0.28秒短音调度，不继续使用样片链条循环。音乐新会话默认关闭，已保存偏好继续沿用。
- 输入结清活动时间时同步更新姿态，修复暂停后的首个渲染帧可能再前进一小步的问题。

## 验收证据与限制

- 最新构建标识和旧模块一致性见 `build.json`；正式六关六个模块的规范化摘要与改造前一致。
- 当前规则/音频/表现/Session测试54项。浏览器专项11项，覆盖普通与减少动态、实际人物像素变化、手掌完整圆周、暂停像素冻结、正常抓取、截止未回收、重开、音频失败重试、保存偏好和三种屏幕尺寸触屏输入。最终结果见 `browser.json`。
- `motion-no-preference.json`、`motion-reduce.json`保留实际游戏中24次回收取样，包含手掌坐标和人物区域像素摘要；不是只检查帧编号。
- `recording.json`记录正常速度空钩、轻金、重石、大金、暂停和结算；实际视频为 `public/sample-demo.webm`。约10秒无声动作摘录 `public/sample-motion-loop.webm`保持原速度，在对照页循环播放。
- 同尺寸浏览器截图：`before.png`是1.3，`rejected-sample.png`是被否定的生成帧图样片，`after.png`是本轮矢量样片。截图均来自运行画面。
- 首次回归发现暂停姿态晚一帧更新，已修正；第二次握柄检查过早在120ms过渡中取样，测试已改为握稳后检查。失败日志保留于`.cache/correction-browser-first.log`及`correction-browser-second.log`，没有将其改写成通过记录。
- 画风、动作自然度和音效听感仍需要用户实际确认。真实手机/Safari尚未验收；声音沿用已选A版，但本轮没有新增人耳听感结论。
