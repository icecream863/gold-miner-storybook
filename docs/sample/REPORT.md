本次交付停在第一关可玩样片，等待提交者体验验收。不能把本文的工程测试当成“已经比经典版自然”或“音效已经好听”的证明。当前完整1.3版本、六关规则与商店没有被替换，也没有推送或部署。

根目录执行 `npm ci`、`npm run sample:build`、`npm run sample:preview`。复跑浏览器检查用 `npm run sample:verify`；生成正常时钟录像用 `npm run sample:record`。录像需要安装Playwright浏览器/录制组件与完整FFmpeg，并设置 `FFMPEG_PATH`。不要在浏览器验收或录制尚未结束时重建产物。

构建位于被忽略的 `.cache/classic-sample-dist/`，含独立入口和所需素材，不包含Session。样片使用浏览器Canvas呈现，直接复用同一规则模型与活动时钟，没有新物理系统；正式Phaser入口暂不整合。六个既有源码模块的不变性由 `preserved-baseline.json` 和跨换行检查 `preserved-baseline-lf.json` 记录，构建时验证。

## 本次实际改变

- 人物使用统一的AI辅助帧图，整体绘制人物、双手和活动手柄，不再以粗线段拼手臂。待机/放手/轻载/重载/入账为五种表现。
- 生成图的完整圆周下半圈不连续，未直接投入循环。最终采用八拍往复棘轮行程（五个不同关键姿势往返），按真实收绳距离推进；没有宣称八张独立连续的整圆动作。靴底区域扫描的下缘差异约1.3世界像素，不能代替对整个人物的观看。
- 为避免再次脱柄，人物和机器主体暂时烘焙在同一帧图；导轮、支架和绳索独立绘制。这与原先静态机器完全拆分的设想有差异，属于样片取舍，机器外形仍有细小帧间差异，需要体验时一起检查。
- 调整为明亮平涂、圆润金块、低饱和石块和简化HUD。没有批量重做六关、商店及特殊物；第一关问号袋沿用既有素材与规则。
- 保留抓取接触偏移，取消周期晃动、物体缩放、通用光圈、金币散射及叠加音阶。入账只出现一次金额提示，动作可被下一次出钩打断。
- 新会话背景音乐默认关闭；旧存储中存在的偏好字段继续沿用。出钩、抓取、入账各用一个短采样，拖拽使用单个持续绞盘源。暂停、重开、关末和切页清理声音，重载适度降低播放速率。
- 声音初剪包含较长静音区，末检已换用更连续的绞盘片段，加入压缩和65ms首尾交叠；没有以整体平均响度代替重物片段检查。

主要新增实现：`src/sample/main.ts` 负责场景与输入；`motion.ts` 负责动作帧；`audio.ts` 负责独立音频生命周期；`model.ts` 只为可选慢速试验覆写大金块回收速度。默认入口仍使用原有数值，六关核心文件未改。

## 经典参考：观察与测量边界

参考 [CrazyGames Gold Miner](https://www.crazygames.com/game/gold-miner)，实际进入其Ruffle运行版本并出钩。截图仅作本地对照，不是游戏素材。

- 正常时钟采集20张截图、其中17张用于灰色钩爪像素位置拟合，摆动周期估计5.39秒，离散采样误差约±0.6秒。当前规则理论周期6.21秒。见 `reference-swing-pixels.json`，不把该估计写成原版常量。
- 捕获一次标价$500的大金块：估计伸钩约1.9秒、回到地表附近约9秒，误差约±0.6秒，见 `reference-heavy.json`。抓取距离不同，不能直接把这两个时长套进当前地图；最后的金额标签也不等同钱包入账时刻。
- 当前样片的出钩速度560、空钩回收600、载物回收公式保持原样。可选慢速入口只给大金块一个×0.7试验，不声称完整复现原版节奏。
- 原版空钩与轻物尚未取得独立可靠计时，不能列为已测数据。原版矿物大小比例、随机布局与当前适配版也存在差异。
