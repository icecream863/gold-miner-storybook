# 参照经典版重新修正放钩

## 先看实际游戏，再改动作

本轮实际启动并操作[用户确认的CrazyGames Gold Miner](https://www.crazygames.com/game/gold-miner)，运行的是其Ruffle页面。观察待机、按下Down、出绳、抓取、回收和复位，未读取游戏内部变量或提取素材投入游戏。

新采样保存在`.cache/classic-motion-20261017/`：第一组16张约1.26秒、包含出钩至抓中石块；重开后fresh组120张约6.52秒，包含出钩、采集和回到摆钩。中间cycle组遇到关卡截止，保留原图但不作为完整动作周期证据。

观察到的动作关系：

- 待机时手靠近机器，而不是垂在腹部下方。
- 出钩时前手向下落、身体前探，出绳阶段保持低手位；没有观察到上一版样片自加的独立拨杆及随后向胸前挥手的动作。
- 回收时重新进入摇柄，结束后回到机器旁的姿态。

截图近景见`reference-classic-poses.png`、`classic-motion-comparison.png`。这些是研究对照，不进入游戏运行资源。截图时间是工具采样时间，包含输入/截图开销，不能当成原版内部动作时长。没有声称逐帧复原经典动画。

## 本轮实际修改

- 删除自加的释放杆和0.56秒多段挥手，改为一次140ms的下落柄动作。约31世界像素的单向下落，之后保持低手位，不持续甩动手柄。
- 待机手停在柄头；出钩、回收和复位均以柄头为控制点。出绳时手柄下落后停止，卷筒仍随出绳变化；回收时手柄按收绳距离旋转。此为依据可见行为设计的本项目适配，不推断原游戏的内部机械实现。
- 回收后180ms内回到待机柄位；新发射可立即打断复位，不增加输入等待。后手改为靠髋姿势，移除跨过机器的长支撑臂。
- 肩、肘、腕继续使用连续外轮廓和长度约束。减少动态仍保留功能动作；暂停冻结，重开回到待机。
- 另修正了绳索出口：原可见导轮在`(550,153)`，实际摆动支点为`(550,180)`。现在可见导轮对齐模型支点，绳线直接从同一点延伸至钩爪，取消导轮下方无支撑的27像素折线。坐标换算共用`SAMPLE_LAYOUT`。

默认摆速、出钩速度、重量、回收公式、碰撞、金额、商店和六关源模块未改变。音效继续沿用用户选定的A版。

## 验证及证据边界

- 类型检查、样片与正式入口生产构建通过；56项测试、13项浏览器专项通过。
- 原放钩测试针对“抬手拨杆”的断言已按实际参考重写：检查单向落柄、落下后稳定、卷筒继续转而手柄不连续空转、手在柄头、接上回收无瞬移。并非仅以“帧号发生变化”验收。
- 普通/减少动态浏览器均取0/60/100/160/300/680ms的实际姿态和人物区域像素，检查放钩期间暂停、重复按键、接触、入账、重开与截止。见`launch-*.json`、`browser.json`。
- 原速整屏带声录像、7秒人物近景和最新构建标识见`recording.json`与`classic-motion-evidence.json`。录制采用正常时钟、真实按键、只读QA辅助瞄准，明确开启减少动态，不当成人类试玩。
