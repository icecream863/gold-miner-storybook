# 放钩与手臂连接修正

本轮只修改独立第一关样片的动作、绘制与必要回归。音效、六关核心规则、商品、默认回收速度和金额未改；未推送、部署。

## 原因和修正

- 原放钩动作只有0.18秒，手部只抬15世界像素，随后出绳仍回到待机。这不是没有动作代码，而是缺少可见且持续的放钩表现。现在是0.56秒的拨杆、抬手、收手轨迹，余下出绳阶段保持观察姿势；普通与减少动态设置均保留。
- 原上下臂、手掌分别绘制封闭描边，导致肩、肘、腕像多个端面相接。现在肩到手掌共用连续外轮廓，只保留袖口分界和短手指线，不再给肘腕画独立端盖。
- 肩点改用与衣服相同的躯干变换；原姿势在重载前倾时上臂会缩短，现复用已有纯几何双段约束校准44/54的肢段长度。关键姿势继续决定弯肘方向，没有新增动画/物理框架。
- 后手移到卷筒顶面，后臂先绘制、肩根被身体遮挡。前臂与手掌在机器前方连贯绘制。
- 发射被接受后立即派发动作事件；重复按键不会重播或重置放钩动作。抓住后从最后放钩手位过渡到握柄，不先跳回待机。动画不阻挡规则发射。

## 证据

- 类型检查与两种生产构建通过。测试56/56通过，浏览器13/13通过，包含本轮新增的普通/减少动态放钩像素变化、暂停恢复、重复按键、手部位移及肘部中心不露背景。
- 新增单元测试覆盖整段出绳动作、骨长、同一时刻暂停不变、放钩转握柄的位置连续性。首次精确肩点变换暴露旧重载骨长问题，已修正而非放宽测试；初次失败日志保留在`.cache/arm-unit-first.log`。
- `launch-no-preference.json`与`launch-reduce.json`是实际游戏6个时点的只读姿态和人物区域像素摘要；对应近景截图在`output/playwright/sample/launch-*.png`。
- `public/sample-arm-demo.webm`是正常速度录屏中截取的7秒人物近景，已放大，未减速。`public/sample-demo.webm`保留约27秒整屏带声演示，录屏明确开启减少动态，只读QA辅助瞄准，真实按键，收入$765。
- 本轮构建/录屏标识、结果与视频摘要见`arm-fix-evidence.json`。旧样片源码、视频和截图保存在`.cache/sample-before-arm-fix-20261017/`；上一轮证据`correction-evidence.json`保留其原构建标识，不当作本轮证明。
