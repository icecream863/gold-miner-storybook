## 实现与取舍

- 分层角色：身体、四种头部表情、前后手臂与手掌独立。关节锚点和素材尺寸集中在RIG；前臂不再折到胡须/胸口，前后层次分别绘制。两段手臂几何解算复用原方案，手柄与手掌仍共用knob点。
- 动作：待机呼吸、放钩手腕动作、轻重回收、280ms入账点头和卸载、炸药反应、挥手庆祝与失败低头。握柄120ms，后手按负载伸向卷扬机支撑。脚底固定，身体只做小角度受力倾斜。后续出钩立即打断入账动作，不增加输入排队或规则停顿。
- 机械和载物：卷筒读取真实收放绳距离，手柄使用0.18减速输出。保留接触偏移，抓取增加短暂收紧，重量越大晃动越小；回收后的卸载影像不参与计分。动物有按实际行程驱动的步态，被抓后停止行走。
- 场景：暖色经典卡通、统一描边和金属/木质材质，重绘矿物、动物、TNT、五商品与控制图标。六关使用不同地层配色和边缘装饰，未改变地图坐标或碰撞半径。
- 界面：Kenney Adventure UI九宫格面板与按钮；替换商店Emoji；购买提示保留在商店文案区域，进入下一关清理。增加独立声音设置及低时间提示。
- 时钟：规则继续使用单调活动时钟，视觉时钟独立允许结果页播放庆祝，在暂停/帮助/隐藏页面冻结。音效和动画不调用入账方法。

## 音乐与音效

背景音乐为Spaghetti Western（Julie Damsgaard / Spring Spring，CC0），素材试听获得提交者明确确认。全曲降低5dB、首尾80ms交叉处理，循环时长约123.26秒，提供OGG和MP3。不是本项目原创音乐，作者、下载来源及加工方式见 [素材说明](ASSETS.md) 和 [38项资源清单](polish-asset-manifest.json)。

音乐默认20%，音效70%，可独立关闭或调节，偏好保存在本机。首次交互解锁AudioContext，资源异步加载；背景音乐保留暂停偏移，菜单/关内/商店使用同一循环源；结算停止音乐突出短旋律。加载较慢或解码失败不阻塞玩法，OGG失败后尝试MP3，设置里可重试。切出页面、帮助、设置和暂停停止声音。

使用Kenney采样音效补充金属、木头、绞盘、卸载与金币，合成音作为反馈层或资源失败降级。音效声部上限16，音乐最多一个循环源，输出经过压缩器控制叠加峰值。音乐和音效文件随工程提供，不依赖外部网站在线播放。

## 失败与修复历史

1. 首次构建发现Node原生类型剥离不支持构造函数参数属性，改为显式成员声明；没有增加编译或测试依赖。
2. 新音乐专项发现设置暂停时重试被播放条件阻止。修复为允许主动加载，仍检查暂停/隐藏状态，加载完成不自动开播。单元与实际浏览器分别验证。
3. 一次测试尚未结束时我重建了dist，旧页面引用的哈希资源短暂404。该失败轮次已保留，最终验证使用固定构建，不据此宣称加载机制错误或通过。
4. 多关专项原180秒执行预算在第五关耗尽，增加到360秒，保留全部断言。未修改游戏时限、降低目标或改写通关状态。
5. 首次带声录像未采集到第一关收益而停止，保留失败日志与原始录像帧；不能仅凭该结果把原因归于音乐等待。第二次创建录像页面未产生帧而取消，后续使用隔离负载、明确阶段日志和菜单音频准备重新录制。第三次实际六关完成，但MediaRecorder音轨Duration头为N/A，使导出工具失败；修复为读取解码进度的最终时间，保留原始文件并恢复合成。最终成片87.32秒，真实音轨峰值−4.2dB，余额$11,485；见 [录像报告](verification/polish-recording.json)。按媒体结束位置估算同步偏移，未做逐帧同步校准。
